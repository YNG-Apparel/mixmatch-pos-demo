# Mix & Match POS Demo

Mix & Match POS is a browser-based point-of-sale and inventory app for clothing boutiques. It gives staff one place to manage products and stock, record sales, and review sales activity.

[**Try the live demo →**](https://yng-apparel.github.io/mixmatch-pos-demo/)

This demo lets you browse the dashboard and inventory, edit products, adjust stock, and try a checkout using fictional sample data.

All products, brands, customers, and orders are fictional. Prices are shown in IDR. Changes you make stay in this browser and are not shared with the live store or other visitors. Select **Reset demo** to restore the sample data.

Checkout is only a simulation. No payment details are collected and no payment is processed.
